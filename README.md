# Sweetrobin's The Winds of Winter Epub!
*Authored by George R. R. Martin and the ASOIAF Fans*


Welcome to Preston Jacob's The Winds of Winter fanfic, converted into .epub format for ease of use on your favorite eReader devices.
For more info, narrated audio chapters, and the PDF version of the fanfic, visit https://www.youtube.com/@PrestonJacobstheSweetrobin

This is an ongoing project. I'll be updating the project as new chapters are released by Preston, as well as continuously improving the source code. This is my first Epub, so please feel free to post any bugs, typos, or suggestions in the Issues section.

A huge thank you to Preston and the entire team behind the fanfic: the only Winds of Winter we'll ever get.

Long live GRRM.
